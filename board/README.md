# Antminer S9 control board v1.3 — справочник

Источники: распиновка платы от пользователя (фото с разметкой) и поддержка платы
в основной ветке U-Boot (`board/bitmain/antminer_s9`, копии в `reference/`).

## Железо

| | |
|---|---|
| SoC | XC7Z010-CLG400, part для Vivado: `xc7z010clg400-1` |
| CPU | 2× Cortex-A9, 666 МГц (ARM PLL 1333 МГц / 2) |
| DDR3 | **512 МБ**: 2× Nanya NT5CC128M16IP-DI (DDR3L, 2 Гбит ×16), шина 32 бита, 533 МГц (DDR3-1066). Другие ревизии бывают на 256/1024 МБ |
| PS_CLK | 33.333 МГц |
| NAND | 256 МБ (MIO 0–14) |
| Ethernet | GEM0 через MIO 16–27, RGMII (`rgmii-id`), MDIO на MIO 52–53, PHY addr 1, Broadcom ID `0362:5E62` (задержки RGMII страпами; в lwIP нужен патч `sw/patches`) |
| SD | SDIO0 на MIO 40–46, WP = MIO 50, CD = MIO 46 (по ps7_init U-Boot) |
| UART | UART1: TX = MIO 48, RX = MIO 49, разъём «UART 3.3V», 115200 |
| Питание | 12 В на J15/J16 |

`ps7_init` из U-Boot рассчитан на 1 ГБ (15 бит строки, 2× чипа 4 Гбит ×16) —
для этой платы (14 бит строки) **не подходит**, DDR настраивается в Vivado
(в базовом проекте выбран эквивалент MT41K128M16 JT-125).

### Тактовые частоты PL (FCLK) в стоковой конфигурации

## Банки ввода-вывода

| Банк | Напряжение | Что на нём |
|---|---|---|
| PL 34, 35 | 3.3 В | GPIO, разъёмы хешплат, вентиляторы, светодиоды |
| MIO 500 (0–15) | 3.3 В | NAND, LED D2 |
| MIO 501 (16–53) | 2.5 В по фото, **1.8 В (LVCMOS18) в ps7_init U-Boot** | Ethernet, SD, UART, кнопки |
| DDR (502) | 1.5 В | DDR3 |

Для банка MIO 501 надёжнее взять LVCMOS18, как в рабочем U-Boot, или измерить VCCO_MIO1.

## PL

Полностью в [`s9_master.xdc`](s9_master.xdc). Кратко:

| Группа | Пины |
|---|---|
| Хешплаты J1..J9 (по 4: PLUG in, RST out, TX out, RX in) | 36 |
| I2C хешплат (SCL1/SDA1 для J1–J8, SCL2/SDA2 для J9) | 4 |
| Светодиоды D5–D8 | 4 |
| Вентиляторы: 1 PWM out + 6 SPEED in | 7 |
| CLOCK_OUT (тестовая точка TP1) | 1 |
| ID платы (резисторы R183–R186) | 4 |

По схеме платы (AntMiner_ControlBoard_XC7010 V1.01, листы 6, 13, 14):

- **Разъёмы хешплат:** PLUG, RST, RXD, TXD, SCL, SDA идут с банка 34 **напрямую** на разъём,
  без буферов и резисторов — любая из этих линий годится и как вход, и как выход.
  A0–A2 — перемычки адреса через 4.7 кОм, EN — с MIO28–36. SCL/SDA подтянуты 1 кОм к 3.3 В.
  Разъём 2×9: 16 VCC (3.3 В), 18 EN, 5 PLUG, 15 RST, 12 RXD, 11 TXD, 4 SCL, 3 SDA,
  8/7/6 A0/A1/A2, 17 NC, 1/2/9/10/13/14 GND.
- **Вентиляторы:** SPEED — подтяжка 10 кОм к 3.3 В, диод 1N4148 к +12 В, напрямую на ПЛИС;
  PWM (J18) общий, на каждом разъёме нагружен 4.7 кОм + 0.1 мкФ на землю.
- Генераторы 100 МГц Y2/Y3 на K17/N18 не запаяны (NC).

Входы, пригодные для логического анализатора без доработок: PLUG×9, RX×9, RST×9, TX×9, SPEED×6.
SPEED (пин 3 разъёмов FAN) проверены меандром с J18 (PWM, пин 4): проходят до 5 МГц
(при 1 МГц и выше фронты затягиваются, скважность 56–65 %).

**FAN SPEED на картинке распиновки перепутаны.** Проверено на плате перемычкой PWM→SPEED:

| Разъём | FAN1 | FAN2 | FAN3 | FAN4 | FAN5 | FAN6 |
|---|---|---|---|---|---|---|
| Ножка | F19 | G18 | F20 | J20 | G17 | H20 |

Разъём FAN: 1 GND, 2 +12 В, 3 SPEED (вход), 4 PWM (выход J18, общий для всех).


## Режим загрузки (перемычки JP1–JP4)

| JP | JTAG | SD | NAND |
|---|---|---|---|
| 1 | 0 | 0 | 0 |
| 2 | 0 | 1 | 1 |
| 3 | 0 | 0 | 0 |
| 4 | 0 | 1 | 0 |

Совпадает с BOOT_MODE Zynq (MIO[5:3]: JTAG = 000, NAND = 010, SD = 110),
то есть JP2 ≈ MIO4, JP4 ≈ MIO5.

## JTAG (J10, 2×7)

Сигналы: 3.3V, GND, TMS, TCK, TDO, TDI, RST, NC. Точная нумерация по фото.
Сейчас используется ESP8266 с прошивкой [esp-xvcd](https://github.com/gtortone/esp-xvcd)
(Xilinx Virtual Cable, порт 2542): D4 = TDO, D5 = TMS, D6 = TDI, D7 = TCK.
